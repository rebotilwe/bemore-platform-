## 2. Service Worker — All Environments

### What Changed
The service worker was previously restricted to the production hostname only (`bemore-tawny.vercel.app`). It now registers on all environments including staging and local development.

### File Modified
`frontend/src/main.ts`

### Before
```typescript
const isProductionHost = window.location.hostname === 'bemore-tawny.vercel.app';
if (isProductionHost && 'serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js').catch(() => {});
} else if ('serviceWorker' in navigator) {
  // Unregister any existing SW in staging/dev to avoid stale cache issues
  navigator.serviceWorker.getRegistrations().then(regs => regs.forEach(r => r.unregister()));
}
```

### After
```typescript
// Register service worker for all environments
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js').catch(() => {});
}
```

### Service Worker Behaviour (unchanged)
The `public/sw.js` (cache name `bemore-static-v2`) uses stale-while-revalidate for static assets only — CSS, JS, fonts, icons. It never caches API calls, HTML navigation, or non-GET requests.

## 3. About Page — Tab-Based Routing

### What Changed
The About page was a single long-scroll page with 7 sections linked by a sticky sub-nav that smooth-scrolled to each section. Each tab is now a **fully independent page** with its own URL, rendering only that section's content.

### New Routes
| Route | Page |
|-------|------|
| `/#/about` | Overview (default) |
| `/#/about/overview` | Overview — Executive Summary |
| `/#/about/group` | Group Structure — HoldCo subsidiaries |
| `/#/about/vision` | Vision & Mission — Envisioning 2035 |
| `/#/about/empowerment` | Empowerment Strategy — HDI Inclusion Model |
| `/#/about/impact` | Impact to Date — Track Record 2013–2023 |
| `/#/about/performance` | Performance Metrics — Current Portfolio |
| `/#/about/opportunity` | The Opportunity — Strategic Rationale |

### Files Modified
| File | Change |
|------|--------|
| `frontend/src/pages/public/about.ts` | Rewritten using page factory pattern — one `makePage(tab)` function generates all 7 pages; each exports as a named export |
| `frontend/src/router.ts` | Registered 7 new routes + updated import |
| `frontend/src/components/nav.ts` | "About Us" link updated from `#/about` → `#/about/overview` |

### Page Structure (each tab page)
Every tab page renders the same hero banner and sticky sub-nav (with active tab highlighted in gold), followed by only that tab's section content, and ends with the "Ready to Partner?" CTA.

### Architecture Pattern
```
makePage('overview') → aboutOverviewPage
makePage('group')    → aboutGroupPage
...
```
All content lives in `SECTION_CONTENT` record keyed by tab. The sub-nav renders all 7 tabs as hash links, marking the current one `.active`.
